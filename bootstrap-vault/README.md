# bootstrap-vault

Central SST project that writes shared configuration and secrets to **AWS SSM
Parameter Store** from GitHub Environment variables and secrets.

App-specific configuration stays in each application repository. This vault
only manages **stage-scoped** values shared across the organization.

## SSM path schema

```
/bootstrap/<stage>/config/*      per-stage variables (String)
/bootstrap/<stage>/secret/*      per-stage secrets (SecureString)
```

### Example parameters

| Parameter | Type |
| --- | --- |
| `/bootstrap/dev/config/ROOT_DOMAIN` | String |
| `/bootstrap/dev/secret/EXAMPLE_API_KEY` | SecureString |

The list of secrets is the `SECRETS` array in the generated region of
`sst.config.ts`. `scripts/env-pull.ts` picks up new keys automatically.

## Adding a secret

1. Add it to `SECRETS` in `sst.config.ts` (or re-run `bootstrap-init`).
2. Add the same name to each GitHub Environment as a secret.
3. Map it in the deploy workflow `env:` block (regenerated by the wizard).
4. Consume it from the app via `ssm:GetParameter` or `npm run env:pull`.

## GitHub environments

Per environment set:

**Variables:** `ROOT_DOMAIN`, optional `AWS_REGION`

**Secrets:** `AWS_ROLE_ARN` plus every key in `SECRETS`

## Local use

```bash
cp .env.example .env
npm ci
npx sst deploy --stage dev
npm run env:pull                 # writes .env from SSM
npm run env:pull -- --stage rev-my-branch
```
